# CODSOFT Data Analytics Internship

## About the Project

This repository contains the tasks completed as part of my CODSOFT Data Analytics Internship.

## Tasks Completed

### Task 1: Data Cleaning and Preprocessing

Cleaned a student dataset using Pandas by handling missing values, removing duplicate records, correcting inconsistent entries, and preparing the cleaned dataset.

### Task 2: Exploratory Data Analysis (EDA)

Explored the student dataset using summary statistics and visualizations to understand patterns and distributions.

### Task 3: Data Visualization

Created eight visualizations using Matplotlib and Seaborn to analyse student marks, age, gender, and city.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook
